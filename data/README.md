# Data notes

`processed/` contains four analysis datasets copied from the research project. File names indicate processing stages; the code and paper should be consulted for exact variable definitions, sources, transformations, and exclusions.

The workflow also uses source data stored outside this repository, including 2015 gridded electricity consumption (night-time-light calibrated), GDL boundaries, GLOPOP-S synthetic population, population grids, climate/economic controls, and national contextual indicators. The local source archive includes 2015 electricity and population rasters, GDL shapefiles and multi-year electricity/GDP archives. Some source files are hundreds of MB or several GB; they are not included in this initial repository because standard GitHub file-size limits prevent a normal Git upload. Record verified source URLs, versions, citations and redistribution terms before public release.

The repository contains selected derived outputs, not all pixel-level caches or every intermediate dataset. Source-data provenance, column dictionary, completeness and reproducibility still require verification.
